# 目标：最小可用的 Tool-Calling Agent
#
# ============ 为什么每个包都写了上界(2026-10-09) ============
# 起因:用户在 Ubuntu 上装完依赖,dummy 一发消息就报
#       TypeError: process() takes no keyword arguments
#
# 根因链(已定位到具体代码行):
#   requirements 只写 "openai>=1.0" → Ubuntu 的 pip 装了最新的 3.22.0
#   → openai 3.x 依赖 httpx2>=2.12(注意:包名是 httpx2,不是 httpx)
#   → httpx2 2.13.1(当前最新)的 _decoders.py:182 有 bug:
#         self._decompress = self.decompressor.process   # Google 版 brotli
#         ... self._decompress(data, output_buffer_limit=...)   # ← 传关键字
#     而 Google 版 brotli 的 process() 是 C 扩展,**不接受关键字参数** → 崩
#     (装了 brotlicffi 就没事 —— 它走 decompress 分支;没装 brotli 也没事
#      —— 它根本不发 Accept-Encoding: br)
#
# 教训:**只锁下界不锁上界,等于把"上游会不会做不兼容改动"赌在运气上。**
# 所以下面每个包都配上主版本上界。上界取"当前最新稳定版的主版本 +1"。
# ============================================================
