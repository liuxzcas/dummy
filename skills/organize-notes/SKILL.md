# 整理笔记

## 步骤

1. 收集待整理的材料(候选列表 / 摘录 / 原始笔记)
2. 去重:合并表述重复的条目,保留信息最全的版本
3. 归类:按主题/维度分组,组内按相关性或时间排序
4. 输出结构化结果:分组标题 + 每组条目(带关键信息)

## 注意事项

- 保留精确值(数字/专名/日期)不概括
- 标注不确定项,不臆造缺失信息
- 输出格式:markdown 清单或表格,便于后续使用
