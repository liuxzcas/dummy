# 检索文献

## 步骤

1. 明确检索主题与关键词(从用户需求中提取 2-4 个核心概念)
2. 用 `web_search` 按关键词搜索(可多轮换词)
3. 用 `web_extract` 读取高价值候选的摘要/简介(标题 + 链接 + 一句话结论)
4. 输出候选列表:标题、链接、一句话摘要、与主题的相关性判断

## 注意事项

- 优先 arXiv(学术论文)与官方文档,其次博客/新闻
- 搜索词用英文通常命中更准;中文需求先翻译核心概念
- 不臆造不存在的链接——每条候选必须来自真实搜索结果
