# 撰写总结

## 步骤

1. 明确输出目标(综述/报告/周报)与读者(自己/团队/公开)
2. 基于材料组织结构:背景 → 主要发现 → 对比/分析 → 结论
3. 逐段撰写,引用材料中的关键事实(保留精确值)
4. 检查:结构完整、无遗漏要点、无臆造信息

## 注意事项

- 正文中文;需要时文首加 `> EN TL;DR:` 英文摘要(三句话内)
- 区分"材料里有的"与"自己的推断",推断要标注
- 长文用标题分层,表格对比优于长段罗列
